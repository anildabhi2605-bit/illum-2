# Skill D — YouTube SEO Specification

## Protected contract dependency

Import/version original Skill D prompt from authoritative source first.

## Purpose

Create a project-aware SEO package using source and script context.

## Inputs

Current project ID/version, source and current script, valid Source Analysis and Script Analysis, current project settings, current approval state.

## Required outputs

- Title
- Description
- Keywords
- Hashtags
- Separate comma-separated tags field

## Fixed output language

SEO output is always Roman Hindi (Latin/English alphabet), regardless of script/content language.

## Process and restrictions

1. Verify current project/script/source versions.
2. Reuse analyses while valid; detect stale evidence.
3. Reconcile claims with source/script and remain truthful.
4. Generate complete structured package.
5. Validate required fields/language and claims.
6. Add disclosure only where warranted by content/use case.
7. Save per project with status/version provenance.

Do not fabricate search volume, guarantee rankings, or add unsupported claims.

## Tests

Required fields; separate comma-separated tags field; Roman Hindi even for English projects; stale source/script detection; unsupported claims rejected/corrected; model output schema validated; approval gate enforced as required by master plan.
