## 2. Invariant Traceability & Process Rules

1. **Evidence Requirement:** Every row must obtain concrete execution test evidence recorded in `07_CHANGE_CONTROL/IMPLEMENTATION_STATUS.md` during its governing phase. This matrix defines acceptance criteria and does not claim any test has passed.
2. **Phase Gating:** No phase exit gate shall be marked passed if any acceptance test mapped to that phase is unexecuted (`NOT RUN`) or failing.
3. **DEC-015 Boundary:** `ACC-001A` remains strictly `PROPOSED / OUT-OF-BASELINE` until `DEC-015` is formally approved by the user.
