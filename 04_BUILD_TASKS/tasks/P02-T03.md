**Phase:** P02 — Configuration and secret safety

## 3. Build steps
1. Document copy example→`.env`.
2. Ensure startup reads new value after restart.
3. Ensure clearing/removing a key results in not-configured after restart.
4. Mask connection state in UI without revealing saved secret.
5. Show explicit restart-required note after file edit.

## 4. Expected deliverables
Config reload-on-start behavior and UI/help text.

## 5. Acceptance criteria
Add/change/remove works after restart; provider becomes unavailable when config removed; app remains usable.

## 6. Required tests
Integration tests with temporary env files; restart simulation; no value rendered in settings.

Run automated tests first, then required integration/manual tests. Record exact command, environment, result and evidence. Tests that were not executed must be labelled NOT RUN; do not infer pass from implementation appearance.
