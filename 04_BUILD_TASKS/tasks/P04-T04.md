## 3. Build steps
1. Count active saved projects in transaction.
2. When at four, identify oldest by created_at.
3. Show named confirmation prompt: "You already have 4 projects. Do you want to delete the oldest project and create this new project?".
4. Cancel/NO preserves all four existing projects and prevents create.
5. Explicit YES confirm calls a safe deletion/replacement orchestration contract; actual full cleanup completes in P13.
6. Protect against concurrent fifth-project creates.

## 5. Acceptance criteria
