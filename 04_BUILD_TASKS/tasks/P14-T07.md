# P14-T07 — Normalize, deduplicate, cluster and rank candidates

**Phase:** P14 — Optional Module E — Idea Research & Discovery  
**Initial status:** NOT STARTED / NOT VERIFIED  
**Task dependency:** P14-T03–T06 as applicable; P14-T01 ranking formula.

## 1. Goal
Turn raw connector results into up to four explainably ranked topics.

## 2. Source inputs
Result schemas, ranking formula version.

Use the original requirements as described in `../../01_BASELINE/PRODUCT_RULES_AND_INVARIANTS.md`; read the related feature spec and the source-of-truth files referenced in `../../00_START_HERE/README_START_HERE.md`. If the source does not define a detail, record it as open; do not silently make it part of the approved product behavior.

## 3. Build steps
1. Normalize time/date/timezone and source metadata.
2. Deduplicate same URL/near duplicates and repeated reposts.
3. Cluster aliases/related queries into topic candidates.
4. Compute trend score separate from evidence confidence.
5. Explain ranking factors and missing-source coverage.
6. Return 0–4 candidates depending on evidence.

## 4. Expected deliverables
Normalization/ranking service and candidate schema.

## 5. Acceptance criteria
No fake ranks/filler; up to four; signal and confidence are separate; scope and score formula shown.

## 6. Required tests
Deterministic ranking fixtures; duplicate inflation tests; partial-connector tests.

Run automated tests first, then required integration/manual tests. Record exact command, environment, result and evidence. Tests that were not executed must be labelled NOT RUN; do not infer pass from implementation appearance.
