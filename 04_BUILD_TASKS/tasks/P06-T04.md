# P06-T04 — Track execution history and usage honestly

**Phase:** P06 — Jobs, retries, usage and execution history  
**Initial status:** NOT STARTED / NOT VERIFIED  
**Task dependency:** P06-T01; P05 adapter response.

## 1. Goal
Persist relevant execution metadata without secrets, invented costs, or raw prompt/response payloads, strictly capping history at latest 100 records per project with FIFO cleanup (DEC-018).

## 2. Source inputs
History field spec; provider usage availability; approved DEC-018 baseline amendment.

Use the original requirements as described in `../../01_BASELINE/PRODUCT_RULES_AND_INVARIANTS.md`; read the related feature spec and the source-of-truth files referenced in `../../00_START_HERE/README_START_HERE.md`. If the source does not define a detail, record it as open; do not silently make it part of the approved product behavior.

## 3. Build steps
1. Store metadata only: project ID, skill ID, provider/model, timestamps (start/finish), duration/latency, status, attempt count, sanitized error code, token usage, fallback reason and user consent.
2. Store usage only when provider exposes it; label amounts actual/estimate/unknown honestly.
3. Strictly omit raw prompts, raw source text, and raw LLM request/response payloads (DEC-018).
4. Implement automatic FIFO retention pruning: retain only the latest 100 execution history records per project, pruning the oldest record upon inserting a 101st record (DEC-018).
5. Ensure cascade deletion of project-specific execution history when a project is deleted (DEC-018).
6. Safeguard shared `.env` file: never delete or modify the shared `.env` file during history pruning or project deletion (DEC-018).

## 4. Expected deliverables
History repository/service, FIFO pruning mechanism, data labels, and cascade cleanup logic.

## 5. Acceptance criteria
No secret leakage; unavailable cost/quota labeled Unknown/Estimate; history joins project correctly; max 100 execution history records per project enforced via FIFO; zero raw prompts/sources/payloads persisted; cascade deletion on project delete verified; `.env` file untouched.

## 6. Required tests
Schema validation tests, sentinel secret scan, 100-record retention FIFO pruning boundary test, metadata-only assertion (verifying absence of raw prompts/payloads), project deletion cascade test, and `.env` immutability test.

Run automated tests first, then required integration/manual tests. Record exact command, environment, result and evidence. Tests that were not executed must be labelled NOT RUN; do not infer pass from implementation appearance.

## 7. Out of scope / prohibited shortcuts
Do not store keys or raw prompt/source text/response payloads (DEC-018). Never delete or modify the shared `.env` file under any circumstance.

- Do not start the next task automatically.
- Do not change protected skill prompts/contracts without recorded user approval.
- Do not claim a connector/provider is supported without adapter and test evidence.
- Do not log or export secrets.
