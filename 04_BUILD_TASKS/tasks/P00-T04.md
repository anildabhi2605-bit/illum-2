## 1. Goal
Define provider and research connector policy, secret storage boundary and data retention before connecting external services.

Use the original requirements as described in `../../01_BASELINE/PRODUCT_RULES_AND_INVARIANTS.md`; read the related feature spec and the source-of-truth files referenced in `../../00_START_HERE/README_START_HERE.md`. 1. Choose first provider adapter candidate after checking real account/capability access.
2. Set required/optional connector status for Module E.
3. Record `.env` plaintext risk, masking, redaction, `.gitignore`, provider-side revoke instructions.

Run automated tests first, then required integration/manual tests. Record exact command, environment, result and evidence. Tests that were not executed must be labelled NOT RUN; do not infer pass from implementation appearance.
